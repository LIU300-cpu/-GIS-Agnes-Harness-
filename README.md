# -GIS-Agnes-Harness-
本项目面向普通用户日常遇到的室内空间认知、测绘问题，提出并实现了一套"基于 Agnes Harness 的室内空间速测与 GIS 分析技能"。项目仅用一部普通手机即可完成室内空间的快速扫描，输出带真实尺寸的房间 3D 白模，并在 Agnes Harness 平台上构建出一项可连续完成五项分析任务的实用技能，涵盖空间重建与量算、功能分区、动线可达性分析、日照采光叠加分析与空间优化方案。项目将地理信息科学"空间数据采集 → 空间分析 → 辅助决策"的核心范式迁移到室内这一小尺度空间，把房间当作一个可测量、可分析的小型地理空间：采用主动式关键帧扫描加参照物标定的低成本方案，取代昂贵的三维扫描仪与 LiDAR 设备。项目精度定位为认知级（±10–20cm），面向布局讨论、教学演示、量房参考等场景，为普通用户提供了一套低门槛、可复用、能连续完成多项分析的室内空间数字化方案。
